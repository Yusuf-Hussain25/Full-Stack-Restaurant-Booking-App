# Full Stack Restaurant Booking App

Full-stack project from my full-stack projects collection.

## Run locally

1. In each app folder, copy `.env.example` to `.env` and fill in your own keys
   (MongoDB / Postgres, auth, payment and storage providers as listed).
2. Install dependencies:

```
cd quickdine/client
npm install

cd quickdine/server
npm install
```

3. Start the backend (`npm run server` or `npm start`) and the frontend (`npm run dev`).
